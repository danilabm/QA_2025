# QA_2025 — Python para Qualidade de Software

Exercícios em Python feitos durante a formação em QA e automação de testes (2025), organizados por aula.

| Aula | Conteúdo | Exemplos |
| --- | --- | --- |
| 1 | Variáveis, tipos e saída formatada | `Desafio Loja.py`, `Nome.py` |
| 2 | Entrada de dados e operações | `Operacoes_de_teste.py`, `Notas_alunos.py` |
| 3 | Estruturas condicionais e coleções (listas, tuplas, dicionários) | `Collections.py`, `Desafio Tupla.py` |
| 4 | Laços `for` e `while`, validação de dados | `Email.py`, `Tabuada.py`, `Vogais.py` |
| 5 | Manipulação de arquivos e pastas com `os` | `Gerenciador de Arquivos.py` |
| 6 | Funções | `Olimpiadas.py`, `Divisão Times.py` |
| 7 | Pandas e geração de massa de teste com Faker | `Massa de Teste - Revisada.py`, `Dataframe.py` |

## Como executar

```bash
pip install pandas faker   # necessários só na Aula 7
python "Aula 1/Desafio Loja.py"
```

A automação de testes com Selenium e BDD da mesma formação está em [Automacao-2025-main](https://github.com/danilabm/Automacao-2025-main).
